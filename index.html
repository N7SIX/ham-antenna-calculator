⌁ Ham Antenna Calculator

by N7SIX

Dimensions for dipoles, verticals, Yagis, loops and quads. Set a frequency, read the lengths in feet or metres, cut once.

Inputs

Design frequency — the part of the band you use most.

Units

End effect and insulation shortening for straight wire. At 0.95 you get the familiar 467 / f dipole and 234 / f vertical — the classic 468 / f field rule is 0.2 % longer. Loops use the published 1005 / f perimeter instead.
